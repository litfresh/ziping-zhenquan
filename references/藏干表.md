# 地支藏干表

| 地支 | 本气 | 中气 | 余气 |
|------|------|------|------|
| 子 | 癸 | - | - |
| 丑 | 己 | 癸 | 辛 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | - | - |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 庚 | 戊 |
| 午 | 丁 | 己 | - |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | - | - |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | - |

**注**：
- 子午卯酉为四正（专气），仅藏一神
- 寅申巳亥为四生（长生之地），藏长生禄旺之气
- 辰戌丑未为四墓，藏余气+入墓+本气
- 土寄旺于四季（辰戌丑未），亦寄生于寅申、寄旺于巳亥
