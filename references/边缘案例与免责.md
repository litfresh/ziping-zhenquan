# 边缘案例处理清单 v2

## 一、时间边界

| 边缘案例 | 处理方法 | 依据 |
|----------|---------|------|
| **交节附近出生** | 精确查该年节气交司时刻。若在交节前后15分钟内，标注"交节临界"，给两种可能 | 第28章 |
| **子时换日** | 默认采用早子时换日（23:00后属次日）。如需晚子时不换日，标注为备选 | 徐注 |
| **真太阳时跨界** | 经度偏离120°较远时校正后时辰可能跨入前一/后一时辰。标注校正前后变化 | 现代预处理 |
| **闰月** | 农历闰月无独立节令。五行月令仍按当月节气定，月柱按正常月柱排 | 命理常规 |

## 二、格局边界

| 边缘案例 | 处理方法 | 依据 |
|----------|---------|------|
| **月令本气未透而中余气透** | 以透出之中余气为用（用神变化）。本气不透干会支则退居次要 | 第10章 |
| **兼透**（多个藏干同时透出） | 兼用。先以司令气为主，再判纯杂。两相得=纯=吉 | 第11章+第16章 |
| **建禄月劫无财官煞食** | 身旺无泄，平庸之格。另寻外格（条件苛刻） | 第45章 |
| **正格不成疑似从/化格** | 严格检查：日主是否真无根？气势是否真一面倒？条件不足则仍以正格论 | 第47章 |
| **官煞混杂** | 去一留一取清。无法取清则以煞论（官多从煞）。混杂未必为忌需看配置 | 第39章 |
| **伤官见官** | 一般破格。例外：(1)金水伤官调候见官；(2)化伤为财作财旺生官论 | 第41章 |
| **财印相碍** | 紧贴→破格。隔位（如年印时财中隔官星）→可解。有合去一神→亦可 | 第31章 |
| **四墓刑冲** | 辰戌丑未同气冲最少妨碍。透干会支即美不劳刑冲 | 第17章 |
| **阳刃辨伪** | 仅五阳干有刃。阴日干在帝旺位≠阳刃（如乙日卯月=建禄非刃） | 第43章 |

## 三、强弱边界

| 边缘案例 | 处理方法 |
|----------|---------|
| **日主极弱但有微根** | 不能从！身弱用印比。区分：弱而有根（扶）vs 弱极无根（从） |
| **日主极旺但有一二克泄** | 克泄无根无力→仍以旺论；克泄有力→可能中和 |
| **身煞两停** | 煞用食制；身略弱则用印化。看微细差别 |

## 四、流年参与规则

> 《子平真诠》以格局配大运为主，流年为辅。第25章仅提及"流年简要参与"。
> 以下规则根据原文精神推导：

| 规则 | 说明 |
|------|------|
| **流年不变成格变格** | 流年力量不足以改变原有格局，只起触发作用 |
| **流年触发大运** | 大运为吉而流年引动（透清/会合）→ 吉应 |
| **流年冲合喜忌** | 冲合用神/相神 → 不吉；冲合忌神 → 吉 |
| **流年透清** | 流年天干透出命局所藏喜忌之神 → 作用明显 |
| **流年与大运关系** | 大运定基调，流年定应期。大运吉+流年吉=大吉；大运凶+流年凶=大凶；吉凶交错则起伏 |

## 五、特殊注意

1. **徐注与原文冲突**：以原文（沈孝瞻）为准。冲突时标注「原文vs徐注」
2. **林注（林君毅补注）**：常批评徐乐吾判断。参考但不作为主依据
3. **古例时辰存疑**：书中案例时辰可能误记（第29-30章指出），分析时标注
4. **五星/子平名词混淆**：古书"禄""贵"常指正官而非神煞（第21章）
