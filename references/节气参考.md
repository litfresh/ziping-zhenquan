# 节气快速参考

## 使用方法

在 SKILL.md 推理模式下，用此表确定月柱。若 LLM 能回忆精确日期则优先使用 LLM 知识。

**使用规则**：
- 出生日 ≥ 某月"节"的日期 → 该月月支
- 出生日 < 某月"节"的日期 → 前一月月支
- 例：2月5日 → ≥立春(2/4) → 寅月。2月3日 → <立春 → 丑月。
- **注意**：闰年2月29日不影响节气判定（立春固定在2/4±1）

## 交节临界处理

若出生日在节气日±1天内，标注【交节临界】，给出两种可能：
```
⚠️ 交节临界：X月X日出生，该年[节气名]在X月X日X时交司。
   若在交司前 → 月柱=[前月]
   若在交司后 → 月柱=[当月]
   以下分析采用[选择]，另一可能见附录。
```

## 年柱边界

- 立春前 → 上一年（如2024年1月出生，在2/4立春前 → 年柱=癸卯，非甲辰）
- 立春起 → 新年

## 真太阳时对月柱的影响

极少数情况下（如出生在节气日23:00+且经度偏东较多），真太阳时校正可能使时辰跨越节气分界。此时需标注并给出两解。
