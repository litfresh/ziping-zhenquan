# 子平真诠八字精解（小马通俗版）

给 Hermes AI 助手用的八字命理分析 Skill。输入出生时间，自动排盘、定格局、看运势，输出一份人人都能看懂的命理报告。

---

## 使用场景

**场景一：快速看盘**

> 「帮我分析八字：1990年7月15日上午10点，男，北京」

Hermes 自动排盘 → 定格局 → 看运势 → 输出结论优先的通俗报告。

**场景二：对比分析**

> 「帮我比较这两个八字：1990年7月15日和1985年3月22日，都是男性，看看哪个财运更好」

**场景三：单问运势**

> 「我最近事业不顺，帮我看看接下来几年运势怎么样」

**场景四：学习命理**

> 「我刚出生的女儿这个八字怎么样？用普通人能听懂的话讲讲」

**场景五：独立跑脚本**

```bash
cd scripts
python3 -c "from pai_pan import quickstart; quickstart(1990,7,15,10,0,'男',116.4)"
```

直接输出排盘结果和结论速览，不经过 AI。

## 怎么安装

```bash
cp -r ziping-skill ~/.hermes/skills/ziping-zhenquan
```

安装后直接对 Hermes 说出出生时间，Skill 自动加载。

---

## 它是怎么算的

1. 把出生时间换成「八字」（天干地支）
2. 按《子平真诠》的规则，从出生月份找出「用神」
3. 根据用神判断格局类型和喜忌
4. 结合大运（10年一步）分析走势
5. 所有结论标注出自书中哪一章
